Coral Bay — Sunset Streets is a top-down 2D open-world crime game in the spirit of GTA 6: explore the sunny fictional seaside city of Coral Bay on foot and by car, steal cars, outrun the police at wanted levels 0–5, and run three story missions. Built by an AI agent for make.fun's "Make GTA 6" bounty, $1,666 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Keyboard and mouse to play.
